# Слайдер амбассадоров: как устроен

Три блока на странице (сверху вниз):
1. **Zero «Амбассадоры»** (сцена): вёрстка из Figma для 1200 и 320, показывает ОДНОГО спикера.
2. **Zero «Карточки амбассадоров»**: данные, по одной карточке на спикера (автокомпоновка).
3. **T123** со скриптом `custom/ambassadors.js` (`docs/ambassadors-t123.html`): читает карточки, подставляет в сцену, листает.

## Классы
Сцена (блок 1):
| Класс | Что это |
|---|---|
| `uc-amb-slide` | группа Slide; на ней можно включить зацикливание классом `uc-amb-loop` |
| `uc-amb-portrait` | контейнер с фото (overflow hidden, всё лишнее обрезается) |
| `uc-amb-bg` | фон (картинка), два слоя «BG desktop» и «BG mobile» |
| `uc-amb-person` | вырезанный спикер, «Person desktop» и «Person mobile» |
| `uc-amb-name-ov` | имя поверх фото (только 1200) |
| `uc-amb-name` | имя под фото (только 320) |
| `uc-amb-title` | заголовок (должность / регалии) |
| `uc-amb-desc1`, `uc-amb-desc2` | описание (две строки; пустая скрывается) |
| `uc-amb-counter` | счётчик «01 / 04» (две копии: 1200 и 320) |
| `uc-amb-prev`, `uc-amb-next` | кнопки (скрипт ставит `is-disabled`) |
Карточка (блок 2): группа `uc-amb-card`, внутри `uc-amb-c-bg`, `uc-amb-c-person` (картинки 1200), `uc-amb-c-bg-m`, `uc-amb-c-person-m` (картинки 320; если нет, берутся 1200), `uc-amb-c-name`, `uc-amb-c-title` (h3), `uc-amb-c-desc1`, `uc-amb-c-desc2`.
Слои, различающиеся по ширине, определяются по имени слоя в Zero («… mobile»), поэтому имена слоёв сцены не менять.

## Как добавить спикера
В блоке «Карточки» скопировать карточку (Ctrl+C, Ctrl+V), заменить 4 картинки (кнопка «Upload to Tilda») и тексты, опубликовать. Счётчик «01 / NN», состояние кнопок и порядок (сверху вниз = порядок слайдов) скрипт берёт сам. Количество карточек не ограничено. На сайте блок с карточками скрывается.

## Поведение
- Спикер: старый уходит влево и в прозрачность, новый приходит справа (при «назад» зеркально). Контейнер обрезает всё выходящее за границы.
- Имя: старое уходит вниз и в прозрачность, новое появляется слева (при «назад» справа).
- Блок с регалиями и описанием: старый уходит в прозрачность с небольшим сдвигом, новый встаёт на место.
- Фон: плавная смена прозрачностью. Счётчик и кнопки обновляются.
- Easing ease-out `cubic-bezier(.22,1,.36,1)` (быстрый отклик, плавное замедление), длительность 700 мс. Во время перехода повторный клик игнорируется. Свайп на мобильном. Клавиши Enter/Space на кнопках. Уважает системную настройку «уменьшить движение».
- Без зацикливания: на первом слайде «назад» неактивна, на последнем «вперёд» неактивна. С зацикливанием (`loop: true` или класс `uc-amb-loop`) кнопки активны всегда, после последнего идёт первый с той же анимацией.

## Настройки
`window.UC_AMBASSADORS = { loop, duration, easing, shift, textShift, hideCards, swipe, respectReducedMotion }` перед скриптом. Состояние и управление: `window.ucAmbassadors` (`go(i)`, `next()`, `prev()`, `index`, `count`).

## Проверка без Tilda
`test/ambassadors-test.html` (макет разметки Zero), открыть через `serve.py`.


## Обновление (исправления по продакшену)
**Классы (актуальная структура).** Абзацы описания: `uc-amb-desc` на каждом абзаце сцены (по порядку сверху вниз), обёртка каждого абзаца `uc-amb-descs` (прячется, если абзац пуст); в карточке абзацы `uc-amb-c-desc` (по порядку). Старые `uc-amb-desc1/2` и `uc-amb-c-desc1/2` тоже поддерживаются. Скрипт ищет элементы сцены ТОЛЬКО внутри блока со `uc-amb-slide`, одинаковые классы в других блоках игнорируются.

**Поведение:**
- Старое содержимое остаётся «призраком» поверх (`position:absolute !important`, стили Zero с !important), поэтому текст не сжимается и не растягивается при смене.
- Спикер и ФИО двигаются в одну сторону (старые уходят туда же и гаснут, новые приходят с той стороны, где новый спикер). Заголовок и описание только гаснут/проявляются, без движения. Фон перетекает прозрачностью. Easing ease-out, 700 мс.
- Живой свайп (мобильные): после сдвига ~8 px скрипт начинает вести переход за пальцем (спикер, ФИО, описание, фон), при отпускании доигрывает до конца, если пройдено 35% (`commitProgress`) или жест быстрый (`commitVelocity`), иначе возвращает назад. На краях без loop игнорируется; вертикальный скролл сохранён (`touch-action: pan-y`).
- Мобильная: высота текстового блока (`uc-amb-info`) резервируется по самой высокой карточке (измерением, пересчёт на resize и после загрузки шрифтов), чтобы счётчик и кнопки не прыгали.
- Мобильная: спикер в рамке привязан к центру и верху (`personPositionMobile`, по умолчанию `50% 0`), через CSS-класс скрипта, поле в Zero на 320 для этого недоступно.
- Пустой абзац: прячется и его обёртка (линия и отступ), лишней линии не остаётся.
- Тонкая линия под абзацами: класс `border-05-bottom` на обёртках; в скрипт добавлен запасной CSS 0.5px для `.uc-amb-descs`, потому что на тестовой странице глобального правила для `border-05-bottom` в CSS страницы найдено не было (есть только `.border-05-mobile.bottom`). Если оно есть в T123 пользователя, дублирование безвредно.

**Тестирование:** `test/live.html` (опубликованная страница + локальный скрипт), `test/live-multi.html` (+ 3 карточки), `test/mobile-frame.html` (iframe 400 px = мобильная раскладка Zero). Анимации тикают только в видимой вкладке; движок можно проверить без таймеров через `ucAmbassadors._debug.begin(target, dir).apply(p)`.
